## About

The Email Template Builder replaces hand-edited HTML emails with a visual editor. Blocks snap into a single-column layout that renders reliably across email clients, and every block picks up your theme's colors and type.

:::shot Email Template Builder

## Workflow

:::steps
1. Pick a starting template or begin from a blank canvas.
2. Drag in blocks - header, text, button, divider, footer.
3. Set colors and content; merge fields stay intact.
4. Preview light and dark, then assign to a WHMCS email.
:::
