Rebuild “Default” from the configurator

Default stays as a one‑click preset — but it isn't magic. It's exactly the two settings below. Set them yourself, or hit Apply, and the live preview + verdict become byte‑for‑byte Default. The ticks below light up as each step matches your current selection in the panel above.

1 Source: pick Self‑hosted font and type InterThe theme's own Inter file, self‑hosted — nothing is fetched from a third party.
2 Apple‑first: tick Keep the device's system font on AppleSan Francisco wins on Apple; Inter loads only on Windows / Linux.
= San Francisco on Apple · bundled Inter on Windows/Linux · 0 external requests — the Default mix, exactly.
